# Exemplars

Put your 3 or 4 best finished cover letters here, in your FINAL wording (after your edits), not Claude's drafts.
Name them `YYYY-MM-company-role.md`. Plain text or markdown is fine.

Good candidates:
- Letters you wrote yourself and were proud of
- Any letter where you rewrote most of Claude's draft, since those teach the most
- One stretch-role letter, so the tone for a role outside your usual lane is on file

Each session reads everything in this folder before drafting.
